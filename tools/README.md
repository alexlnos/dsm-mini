# Снимки экранов для документации

Скриншоты в `docs/screenshots` сделаны на **демо-данных**, а не на живом NAS:
в README нельзя показывать чужие раздачи, имена машин и папок.

`fixtures.js` — эти самые данные, `shoot.js` — сценарий обхода приложения.
Ответы API подменяются на уровне браузера, поэтому NAS для съёмки не нужен —
достаточно запущенного сервиса.

```bash
cd tools && npm i playwright
TELEGRAM_BOT_TOKEN=... OUT=./out node shoot.js
```

Дальше снимки уменьшаются в полтора раза и переводятся в WebP: 21 КБ вместо
135 КБ на файл при тех же пятидесяти экранах.
