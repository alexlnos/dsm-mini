# Установка

## Synology, через Container Manager

Способ для тех, у кого NAS и сервис на одной машине.

1. Соберите образ или возьмите готовый: `ghcr.io/alexlnos/dsm-mini:latest`
   (архитектура `amd64` для большинства моделей, `arm64` для бюджетных).
2. Container Manager → Проект → Создать, вставьте
   [docker-compose.yml](docker-compose.yml) и укажите переменные из `.env`.
3. Панель управления → Портал приложений → Обратный прокси-сервер: правило
   с `ds.example.com:443` на `localhost:8080`, сертификат Let's Encrypt.
4. У бота в @BotFather задайте адрес Mini App: `/setmenubutton` → тот же
   `https://ds.example.com`.

**Порт 80 для этого имени не проксируйте**: через него DSM продлевает
сертификаты Let's Encrypt.

## Отдельная машина

```bash
cp .env.example .env   # заполните
docker compose -f deploy/docker-compose.yml up -d
```

## Проверка

```bash
curl -s https://ds.example.com/healthz
```

Ответ `{"status":"ok"}` означает, что сервис жив. Доступ к данным он при этом
не открывает: любой запрос к `/api/` без подписи Telegram получает 401.

## Учётная запись DSM

Отдельный пользователь, а не администратор:

1. Панель управления → Пользователи и группы → Создать.
2. Права: только на нужные пакеты — Download Station и File Station.
3. Двухэтапную проверку **не включайте**: одноразовый код в конфигурации
   работать не будет.
4. Дайте доступ только к тем общим папкам, которые нужны для закачек.
